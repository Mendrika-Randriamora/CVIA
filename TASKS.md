# Tâches — Phase actuelle : Conception

## Objectif de la phase

Poser les bases du projet avant de commencer le développement :
- Analyse des besoins (fonctionnels et non-fonctionnels)
- Dictionnaire de données
- MCD (Modèle Conceptuel de Données)
- Puis, à la suite : MLD/MPD, diagrammes de cas d'utilisation, maquettes/wireframes

## Comment proposer votre travail

Chaque membre réfléchit de son côté puis partage sa proposition à l'équipe. Process :

1. Créer un fichier à votre nom dans le dossier `conception/` (ex : `conception/Mendrika.md`)
2. Rédiger votre proposition dans ce fichier (besoins identifiés, entités/attributs/relations, etc. selon la tâche en cours)
3. Commit avec le type `design` (ex : `design(conception): proposer le MCD - Mendrika`)
4. Ouvrir une Pull Request pour partager avec l'équipe (voir `CONTRIBUTING.md`)
5. Discussion en équipe (Discord ou en commentaires de la PR) pour comparer les propositions
6. Une fois un consensus trouvé, une version consolidée est créée par l'équipe (ex : `conception/MCD-final.md`)

**Important :** ne modifiez pas directement le fichier d'un autre membre. Si vous avez des remarques, passez par les commentaires de PR ou par Discord.
